# Changelog

## 1.1.0
- The tool now stays active after a building is saved, so you can digitize the next one immediately.
- `Esc` / right-click with fewer than 3 points discards the current building; pressing again with nothing in progress exits the tool.

## 1.0.0
- Added keyboard shortcut `Ctrl+Alt+B` to start the tool (rebindable in Settings → Keyboard Shortcuts).
- Added in-tool keys: `Enter` finish, `Backspace`/`Delete`/`Ctrl+Z` undo last corner, `Esc` cancel.

## 0.9.0
- Initial version.
